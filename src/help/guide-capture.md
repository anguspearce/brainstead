## Capture a task from anywhere
Press `⌃⌥Space` in any app, type the task and press `↩`. It goes to the To Do list under Other. `due: fri`, `defer: +3d` and `@calls` set a due date, a defer date and a context. Captures save only with Read-only off in [Settings › Vault](app:settings/vault).

## Catch a thought in the Scratchpad
Press Tab in the same box to switch to **Thought** (`⇧↩` for a new line). It goes to the Scratchpad under the date and time. Tasks and thoughts wait in the [Inbox](app:inbox) until you clarify them. The same box is on [Today](app:today).

## Write a new note
Press `⌘N`, pick a template or an empty note, and give its type, title and date; Brainstead names the file and opens it in [Notes](app:notes). `⌥⌘1`, `⌥⌘2` and `⌥⌘3` switch between View, Edit and Source.

## Link and tag as you write
Type `[[` to link a note and `#` to add a tag, picked from suggestions. A task line (`- [ ] Send Lena the brief`) takes capture's shorthand, such as `due: tomorrow`, and shows on [Tasks](app:tasks) at once.

## Save, or keep a draft
Press `⌘S` to save. Leaving with unsaved changes offers **Keep as draft**; drafts show first under Continue where you left off on [Today](app:today), with **Discard**.
