Each key works where its heading says. Quick capture's shortcut is set in [Settings › General](app:settings/general); the default is shown on its button in Settings.

Keys are shown for this computer: Windows uses Ctrl, Alt and Shift where the Mac uses its own modifier keys, and the screen shortcuts are Ctrl+Shift+1 to 0 on Windows. Read aloud, Export PDF and Quick Look are Mac only for now.

## Anywhere
- `⌘K` — Search or jump anywhere
- `⌘⇧F` — Search page (also `⌥⌘6`)
- `⌃⌥Space` — Quick capture, from any app
- `⌘N` — New note; `⌘↩` creates it
- `⌘Z` — Undo the last change
- `⌘[` `⌘]` — Back, forward
- `⌥⌘1 … ⌥⌘9` `⌥⌘0` — Today, Inbox, Tasks, Projects, Changes, Search, Ask, Notes, Wiki, Sources
- `⌘,` — Settings
- `?` — Help for this screen
- `Esc` — Clear the screen's search box
- `⇧⌘?` — Brainstead Help (Help menu)
- `⌘Q` — Quit (asks first, and about unsaved changes before that). Mac only: on Windows use **File › Exit**, or `⌘Q` in the menu bar window

## A note
- `⌘1` `⌘2` `⌘3` — View, Edit, Source
- `⌘.` — Focus mode; `Esc` leaves it
- `⌘S` — Save
- `⌘F` — Find (and replace in Edit and Source); `↩` `⇧↩` next, previous
- `⌘B` `⌘I` `⇧⌘X` `⌘E` `⇧⌘H` — Bold, italic, strikethrough, code, highlight
- `⌘=` `⌘-` `⌘0` — Bigger, smaller, usual text size
- `⌘P` — Export PDF
- `⇧⌘P` `F8` — Read aloud, or play and pause
- `Space` `Esc` — Play or pause, stop (reading aloud)
- `F7` `F9` — Previous, next paragraph (reading aloud)
- `⇧⌘R` — Rename
- `⌥⌘R` — Reveal in Finder (Show in Explorer on Windows)
- `⌥⌘C` — Copy path
- `[[` `#` — Link a note, add a tag
- `⌃Space` — Suggestions in a template's `<% %>` tag
- `↩` `Tab` — Take the chosen suggestion
- `due:` `defer:` `start:` `created:` — A date: tomorrow, fri, +3d
- `@calls` `effort:15m` — A context and effort, in a task or Quick capture

## ⌘K
- `↑` `↓` — Move
- `←` `→` — Across the Go to columns (before you type)
- `Tab` `⇧Tab` — All, Notes, Wiki or Sources
- `↩` — Run the selected item
- `⌘↩` — Search everything
- `Esc` — Close

## Quick capture
- `↩` — Save
- `Tab` — Switch between Task and Thought
- `⇧↩` — New line in a thought
- `↑` `↓` `↩` `Tab` — Choose, take a suggestion
- `Esc` — Close the suggestions, then the window

## Menu bar window
- `⌘O` `⌘T` `⌘J` `⌘,` — Open Brainstead, Today, Ask, Settings
- `⌘Q` — Quit
- `Esc` — Close the window

## Lists
- `↑` `↓` — Move between rows
- `↩` — Open
- `Space` — Quick Look (Trash; Word, PowerPoint or Excel sources; Mac only)

## Task lists
- `↑` `↓` — Choose a task, across lists
- `↩` — Open it (its text on Tasks, its note elsewhere)
- `Space` — Tick or untick
- `⌫` — Delete (`⌘Z` undoes)
- `/` — Search tasks (on Tasks)

## Inbox
- `J` `K` `↑` `↓` — Next, previous
- `↩` — Accept the suggestion
- `N` `P` `W` — Next action, new project, waiting for
- `2` `S` — Done in two minutes, someday
- `R` — File as reference, or keep a capture in Sources
- `⌫` — Delete (a capture goes to the Trash)
- `I` — Ingest into the wiki (a capture)
- `M` — Make a meeting note (a transcript)
- `D` — Draft a reply (a captured email or Teams thread)
- `A` — Ask about this source (a capture)

## Bookmarks triage
- `K` `I` `T` `A` — Keep, ingest into the wiki, make a task, archive
- `⌫` — Remove the bookmark
- `↩` — Accept the suggestion, or remove a missing bookmark

## Changes
- `J` `K` — Next, previous change
- `A` `R` — Accept, reject the held change
- `⌘↩` — Accept every held change in its run
- `↑` `↓` — Step through the search's matches

## Draft reply
- `↩` — Send what you typed in Ask for a change

## Ask
- `⌘T` — New chat
- `↩` `⇧↩` — Send, new line
- `Esc` — Stop the answer
- `↑` — An earlier message (empty box)
- `→` `Tab` — Take the suggested next message (empty box)
- `/` `[[` `#` — A skill, a note, a tag
